# Суми — японский, черта за чертой

Статический тренажёр кандзи, хираганы и катаканы. 1000 частотных кандзи по KANJIDIC2 с русскими учебными значениями и английскими оригиналами; 46 основных знаков каждой азбуки и дополнительные формы. Письмо по чертам, голос устройства, упражнения на слух и полные страницы A4 для печати.

## Запуск

Открой опубликованный сайт на компьютере или телефоне. Для разработки: `python3 -m http.server 4173 --bind 127.0.0.1`, затем http://127.0.0.1:4173.

Для озвучки нужен японский голос устройства. По умолчанию его выбирает браузер; можно выбрать конкретный голос. Прогресс и выбор голоса сохраняются в этом браузере, без сервера и синхронизации между устройствами.
